# College C Programming Examples

A collection of beginner C programs for college coursework and practice.

The source programs are from [ShrihariPatil11/C-PROG.SHREE](https://github.com/ShrihariPatil11/C-PROG.SHREE). Filenames here describe each program's purpose. Program contents are preserved from the source repository.

## Programs

- `positive_negative_or_zero.c`
- `print_two_dimensional_array.c`
- `c_programming_welcome.c`
- `sum_three_integers.c`
- `adult_or_minor.c`
- `print_array_in_reverse.c`
- `student_introduction.c`
- `color_from_number.c`
- `day_from_number.c`
- `check_divisible_by_five.c`
- `even_or_odd.c`
- `compare_two_numbers.c`
- `welcome_message.c`
- `grade_from_marks.c`
- `pass_or_fail.c`
- `find_smallest_array_value.c`
- `sum_array.c`

Compile an individual program with a C compiler, for example:

```sh
gcc even_or_odd.c -o even_or_odd
./even_or_odd
```
